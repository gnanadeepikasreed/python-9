
# Multi-Currency Travel Budget Analysis

## Description
This project converts travel expenses from different currencies into Indian Rupees and compares total expenses with the available budget.

## Features
- Accepts travel budget.
- Supports USD, EUR, and INR.
- Converts currencies into INR.
- Adds a 2% conversion fee.
- Calculates total travel expenses.
- Checks budget status.
- Identifies the largest expense category.

## Concepts Used
Variables, data types, operators, conditional statements, loops, strings, and lists.

## Language
Python 3

## How to Run
python Multi_Currency_Travel_Budget.py
